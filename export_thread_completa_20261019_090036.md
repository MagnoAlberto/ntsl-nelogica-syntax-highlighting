Para vincular a pasta local ao seu repositório remoto e subir os arquivos, execute no terminal dentro desta pasta:

```powershell
# 1. Inicializa o repositório Git local
git init

# 2. Adiciona todos os arquivos
git add .

# 3. Faz o primeiro commit
git commit -m "feat: initial commit - ntsl syntax highlighting"

# 4. Define o branch padrão como main
git branch -M main

# 5. Vincula ao repositório remoto do GitHub
git remote add origin https://github.com/MagnoAlberto/ntsl-nelogica-syntax-highlighting.git

# 6. Envia os arquivos para o GitHub
git push -u origin main
```

*(Nota: Criei previamente um arquivo [.gitignore](file:///C:/Users/magno/OneDrive/Tech/Snippets/plugins/ntsl-nelogica-syntax-highlighting/.gitignore) básico na raiz para evitar subir arquivos temporários ou pacotes futuros como `*.vsix` e `node_modules`).*
